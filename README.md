# Programación Avanzada — Alonso Leonard

Proyectos de NetBeans (Maven + Java FXML). Cada carpeta `EjercicioX_Y_*` es un proyecto independiente:
ábrelo en NetBeans con **File → Open Project** y ejecútalo con **Run** (o `mvn clean javafx:run`).

## Práctica 1 — Interfaces básicas (FXML)
| Ejercicio | Proyecto | Descripción |
|---|---|---|
| 1.1 | `Practica1-InterfacesBasicas/Ejercicio1_1_Edad` | Edad en años y meses a partir de la fecha de nacimiento |
| 1.2 | `Practica1-InterfacesBasicas/Ejercicio1_2_Desglose` | Desglose de dinero en billetes y monedas |
| 1.3 | `Practica1-InterfacesBasicas/Ejercicio1_3_Cifras` | Cifras y divisores de un número |
| 1.4 | `Practica1-InterfacesBasicas/Ejercicio1_4_Tabla` | Tabla de multiplicar |
| 1.5 | `Practica1-InterfacesBasicas/Ejercicio1_5_Gastos` | Control de gastos semanales |
